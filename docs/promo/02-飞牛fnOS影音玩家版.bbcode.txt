[size=3][b]一、 NAS 与影音玩家最纠结的“痛点”[/b][/size]

各位玩飞牛 fnOS 或群晖的大佬，平时肯定遇到过这个尴尬难题：
1. [b]如果不给 NAS 挂旁路由[/b]：Emby / Jellyfin / Plex 刮削海报墙极其缓慢甚至满屏裂图，SubHD 字幕下载失败，Docker Hub 拉取镜像三天两头超时报错；
2. [b]如果把 NAS 网关改成旁路由[/b]：qBittorrent / Transmission 跑 BT/PT 下载时，几百 G 甚至几个 T 的大流量一不小心全走到外部加速通道上，不仅非必要外部带宽损耗严重，节点流量秒空，还可能因为滥用协议被封号！

难道就不能既让海报墙与 Docker 极速秒拉，又让 PT 下载 100% 走国内千兆物理宽带满血直连吗？

[size=3][b]二、 影音/NAS 专属分流模式是怎么工作的？[/b][/size]

在 CubeX 局域网设备控制台里，找到你的飞牛 NAS 或客厅蓝光播放机，点击切换为 [b]【🎬 影音专属模式】[/b]，系统将自动加载双核复合智能编排：

- 🚀 [b]海报墙与元数据极速刮削[/b]：[color=#0066cc][b]api.themoviedb.org[/b][/color]、[color=#0066cc][b]thetvdb.com[/b][/color]、[color=#0066cc][b]fanart.tv[/b][/color]、[color=#0066cc][b]subhd.tv[/b][/color] 以及 Docker 官方源，全自动走低延迟国际加速通道，海报秒出、简介秒加载、封面瀑布流丝滑刷出；
- 🏠 [b]PT/BT 大流量 100% 物理直连[/b]：所有 Tracker 宣告、P2P 节点握手与大流量数据传输，100% 走局域网与运营商物理网关直接满血直通，跑满你的 2.5G/万兆外网带宽，彻底杜绝任何外部流量损耗！
- 📺 [b]客厅蓝光机/电视无缝体验[/b]：电视机即便播放 4K 原盘，内网数据流原地直通 NAS，主路由 CPU 占用仅 1%，客厅看电视永远零卡顿！

[size=3][b]三、 飞牛 fnOS 极速 2 步部署（Docker Compose）[/b][/size]

CubeX 为飞牛 fnOS 用户量身定制了 Host 模式部署模板，零繁琐配置：

#### 步骤 1：在飞牛新建 [color=#0066cc][b]docker-compose.yml[/b][/color]
[code]version: "3.8"

services:
  cubex:
    image: fyasshole/cubex:latest
    container_name: cubex
    restart: unless-stopped
    network_mode: host
    privileged: true
    cap_add:
      - NET_ADMIN
      - NET_RAW
    devices:
      - /dev/net/tun:/dev/net/tun
    volumes:
      - /vol1/1000/docker/cubex/data:/app/data
      - /vol1/1000/docker/cubex/etc:/app/etc
      - /etc/localtime:/etc/localtime:ro
    environment:
      - TZ=Asia/Shanghai
      - CUBEX_EDITION=docker[/code]
*(注意：请将 [color=#0066cc][b]/vol1/1000/docker/cubex[/b][/color] 替换为您飞牛系统真实的存储路径)*

#### 步骤 2：启动并进入后台
启动后，在浏览器直接打开：[color=#0066cc][b]http://飞牛IP:2026[/b][/color] 即可看到高质感的 Twilight Crystal 暮光冰晶控制台！

[size=3][b]四、 主路由加一条回指，全家立享[/b][/size]

只需在您的主路由（RouterOS / 爱快 / OpenWrt）静态路由里加一条：
- [b]目标网段[/b]：[color=#0066cc][b]198.18.0.0/15[/b][/color]
- [b]网关[/b]：填写飞牛 NAS 的内网 IP

全家手机、电视、电脑[b]完全保持系统默认 DHCP（网关和 DNS 指向主路由）[/b]，什么都不用改，新设备进门连上 Wi-Fi 自动享受分流与去广告，全家永不断网！
