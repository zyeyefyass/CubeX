- 家里来个亲戚朋友，连上 Wi-Fi 发现根本打不开网页，因为他们的手机没去手动填“旁路由静态网关”；
- 界面上一堆复杂专业术语：DNS 劫持、Fake-IP、TProxy、MRS 规则流、SNI 嗅探……想微调一个网站的分流，查了一整晚教程还是搞不懂。

**有没有一种可能：你折腾你的软路由，家里人完全感觉不到任何变化？新设备进门照样像用普通路由器一样连 Wi-Fi 就全自动加速？**

这就是 **CubeX** 诞生的初衷——打造一款“守护家庭和睦的家电级零感网关”。

### 二、 三个“让全家彻底省心”的神奇体验

#### 1. 全家设备“零修改”
所有手机、电视、平板，**保留出厂系统的自动获取 IP（DHCP）**。你不需要在手机里填任何静态网关，也不用担心来客人的设备水土不服。连上 Wi-Fi 就能享受全球加速与全域去广告！

#### 2. “老婆再也不拔插头”的断网保底
CubeX 拥有底层的断网逃生看门狗。就算你在后台升级系统、甚至把旁路由电源拔了，主路由器会在 3 秒内自动切换回普通宽带直连模式！客厅播电视依然流畅，微信视频绝不掉线，家庭地位稳如泰山！

#### 3. 顶栏「一句话自定义网站分流」
不再需要去写晦涩难懂的规则代码。控制台顶栏直接输入网址（如 `tmdb.org`），提供三大醒目按键：
- `【⚡ 强制走加速】`
- `【🏠 强制走直连】`
- `【🛑 屏蔽该网站】`  
一键指派，秒级生效，小白也能一眼看懂、一键搞定！

### 三、 30 秒一行命令开箱

如果你家里有 PVE 小主机、飞牛 NAS 或轻量 Linux 服务器，打开终端粘贴回车即可：
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/zyeyefyass/CubeX/main/install_pve_lxc.sh)"
```

进入浏览器打开 `http://你的IP:2026`，即可体验现代全息毛玻璃控制台。
